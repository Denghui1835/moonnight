# 《月夜》三分钟演示脚本

> 目标：三分钟内让评委看懂「这是什么、为什么恐怖、技术在哪」。
> 主曲：`docs/music/moonnight-metal.wav`（原创、程序合成）。整片只使用这一首配乐，不加任何第三方音乐。

## 一、成片规格

| 项目 | 建议 |
|---|---|
| 画幅 / 帧率 | 1920×1080 / 60fps（手机竖屏镜头可后期加边框） |
| 浏览器窗口 | 1280×800 以上，缩放 100%，隐藏书签栏 |
| 录音 | 旁白单独录，-16 LUFS 左右；配乐 -10.8 LUFS，旁白段落压低 6–8 dB |
| 字幕 | 关键机制与按钮名上字幕；片尾注明「配乐原创、程序合成」 |
| 时长 | 2:50–3:00 |

## 三、录制步骤

1. `npm run dev`，用 **Microsoft Edge** 打开 `http://localhost:5173/`，窗口 1280×800，缩放 100%（3D 场景需要 WebGL，录制前先在 `edge://gpu` 确认硬件加速已开）。
2. OBS 新建「窗口采集」，1920×1080 画布，60fps；音频只采集桌面输出。
3. 先用键盘模式完整跑一遍：教学 → 第 1 关 → 故意跳错 → 结算 → 重开 → 第 3 关 → 第 6 关 → 终章。**同一局内不要剪断节拍**，方便后期对拍。
4. 摄像头镜头单独再录一条：允许摄像头，做「张开 / 举高 / 垂下」，保留浏览器授权弹窗半秒，证明是真摄像头。
5. 手机竖屏镜头单独录一条：DevTools 设备模拟 375×812，展示四键舞蹈板和竖屏构图。
6. 导入 `docs/music/moonnight-metal.wav` 作为唯一配乐：
   - 0:00 从曲子第 0 秒开始，前奏正好压标题；
   - 1:50 让副歌落在第 3 关金属层切入处；
   - 2:35 之后保留尾声，让最后一句旁白落在收束和弦上。
7. 录旁白，按分镜表逐句录，语速放慢；恐怖段落留 1–2 秒静默。
8. 字幕：机制名（「循环靠近」「跳错即死」「金属编曲层」）用同款月白色，不加花字。
9. 导出 H.264 / AAC，文件名 `moonnight-demo.mp4`。

## 四、拍摄注意事项

- **不要用第三方音乐**：包括 Thriller、Beat It 的原曲或翻奏。成片配乐只用仓库里的 WAV。
- **不要加速画面冒充难度**：BPM 提升是游戏内真实机制，直接录即可。
- 摄像头镜头保证脸部/上半身入镜，光线从正面来，避免逆光。
- 手机竖屏镜头只用于展示 375px 适配，不占主叙事。
- 片尾必须出现：`配乐 / 美术 / 代码均为原创；配乐由 Web Audio 程序合成`。
