## 一句话

一个用摄像头替你照镜子的恐怖舞蹈游戏：镜中的领舞戴着黑色礼帽，身后的队伍一直在靠近；你只能靠跟对每一拍活下去。

## 玩法

1. **跟练**：镜中人做一个动作，你在同一个节拍里做出来。
2. **键盘模式**：方向键 / WASD 对应 `↑ 张开、↓ 垂下、← 左手抓、→ 右手抓`，难度与摄像头完全一致。
3. **手机触控**：触屏设备自动出现底部四键舞蹈板，点按即判定，评委可以直接用手机试玩。
4. **教学关**：第 0 关不会死，可以「重看这个动作」「重看全部」，也可以直接「跳过教学」。
5. **肉鸽**：正式关一旦跳错，无论僵尸离你多远，都会瞬间扑上来。回到第 1 关。
6. **六关**：BPM 从 128 一路升到 168，动作数从 4 个增加到 8 个；第 3 关起切换重金属编曲层。
7. **终章**：跳完最后一支没教过的舞，你会知道队伍里第一个人的来历。

## 操作

| 操作 | 键位 |
|---|---|
| 跟舞（四个方向） | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 手机 / 平板 | 底部四键舞蹈板，点按即判定 |
| 静音 / 取消静音 | `M` |
| 教学重看 | 界面按钮 |
| 摄像头模式 | 允许浏览器使用摄像头即可，无需穿戴设备 |

摄像头不可用、模型加载失败或用户拒绝授权时，游戏会自动切换到键盘模式，并保留本次进度入口，不会卡在加载界面。

## 恐怖从哪来

- **一直在靠近**：僵尸不会一次冲上来。它们循环地逼近，在快要抓住你的一瞬间退回远处，再重来。你跳对时，这条循环是安全的；你跳错时，它们不再等。
- **镜子**：整块屏幕就是镜面。领舞只存在于镜中，房间里没有这个人。
- **看不清**：全部角色都是程序化黑色剪影，没有贴图、没有面孔，恐怖来自轮廓和节奏。
- **声音**：心跳、门轴、乌鸦、远处惨叫都长在节拍上；第 3 关起，失真吉他和双踩接管配乐。

## 原创配乐

### 主题曲《dead beat》

游戏内的背景乐是 `public/music/dead-beat.mp3`，**由我用 AI 音乐生成工具合成，是我自己的原创作品**——旋律、编曲、鼓组全部由我生成与挑选，没有翻唱、没有采样任何既有歌曲。

- 时长 5:33，129.2 BPM。我用 librosa 跑了真实的节拍与小节分析，拿到全曲的段落边界：前奏结束约在第 32 拍，breakdown 从第 564 拍开始，高潮段是第 598–680 拍，尾声从第 680 拍之后开始。
- **整套编舞是照着这首歌的真实段落写的**，不是估出来的：第 1–6 关的动作表逐关加花、每关的拍数密度递增；终章拆成 breakdown 与高潮两段，动作收回到「伸手、退步、转身、抬头」这四个核心动作，一遍一遍重复，不再提速。
- 游戏里这首歌**全程只播一遍**：进教学、过关、换关都不重启、不打断。节拍不再靠假时钟估算，而是直接锚在这条音轨的实际播放位置上（`AudioContext.currentTime` 减去起播时刻），所以舞者和鼓点是对齐的；音频被系统挂起时自动退回帧时钟，恢复后重新对齐，不会跳拍。

### 早期实验曲《moonnight-metal》（已停用，代码保留）

`docs/music/moonnight-metal.wav` 是项目早期做的**程序合成**重金属乐曲：65.66 秒、148 BPM、D 弗里几亚小调，由 `src/metal.ts`（编曲引擎）经 `src/metalRender.ts`（`OfflineAudioContext` 离线渲染）生成并导出为 16-bit 立体声 WAV，没有采样、没有外部音源，也没有引用任何既有作品的旋律或 riff。

它现在**不再作为游戏内的背景乐**：换成真实音轨之后，这套音序器退居为兜底——只有在音频文件缺失或加载失败时才会启用，相关代码与音频文件都完整保留，作为这个项目的一段技术存档。细节见 [music/README.md](music/README.md)。

## 技术亮点

| 模块 | 实现 |
|---|---|
| 渲染 | Three.js r170 实时 3D：程序化人偶（正向运动学骨架）、真实镜面反射（`Reflector`）、Bloom、体积光、菲涅尔轮廓光；零图片素材，地面/窗/尘埃/演出单全部由 canvas 程序生成 |
| 降级 | WebGL 不可用时自动退回 Canvas 2D 剪影场景，玩法与判定完全一致 |
| 体感 | MediaPipe PoseLandmarker (lite)，模型与 wasm 全量本地化，不依赖外网 |
| 判定 | 10 个加权姿态特征，0–1 匹配分；键盘模式走同一套节拍窗口 |
| 音乐 | 真实音轨播放（Web Audio `AudioBufferSource`），节拍锚定在音轨实际播放位置上；文件缺失时自动回退到原有的程序音序器（25ms 轮询 / 120ms 前瞻） |
| 音效 | 门轴、脚步、乌鸦、惨叫、玻璃、尸群六类全部换成真实采样文件，逐项失败可回退合成 |
| 兼容 | 摄像头失败自动降级、轨道显式关闭、按钮恢复、桌面与手机竖屏各自构图 |
