`moonnight-metal.mp3` 是同一母带的 192 kbps 试听版（1.6 MB），内容与 WAV 完全一致，方便网页/演示脚本直接引用。游戏站点也在 `public/music/` 下提供同一份 MP3。

### 编制与音色

- **双轨节奏吉他**：左右声道各一台，锯齿波叠加五度/八度，经 `WaveShaper` 强失真 + 高通 + 中频提升 + 低通“箱体”滤波，带拨片噪声。
- **主音吉他 solo**：高增益失真、颤音、滑音（弯音）与 0.31s 反馈延迟，D 小调五声音阶 + 降二级/降六级。
- **贝斯**：锯齿波 + 低八度正弦，轻失真，跟随 riff 根音。
- **鼓**：合成底鼓（含点击声）、双踩 16 分、军鼓 + 桶鼓加花、踩镲/吊镲，带卷积混响。
- **恐怖音效**：乌鸦、心跳、门轴、远处惨叫、低频 drone，穿插在段落转换处。
- 参考风格：80 年代恐怖摇滚的叙事氛围与硬摇滚律动，仅借鉴配器与气质，旋律与 riff 全部原创。

### 生成方式

`src/metal.ts` 是游戏与导出共用的金属编曲引擎；`src/metalRender.ts` 用 `OfflineAudioContext` 离线渲染、归一化并编码 16-bit PCM WAV。游戏内从第 3 关起由 `src/audio.ts` 实时调度同一套编曲层，因此本文件与实机听感一致。

### 循环

首尾都落在 D 强力和弦与镲片上，文件末尾有 60ms 淡出避免爆音；演示视频可直接整段使用，网页播放器可开 `loop`。
