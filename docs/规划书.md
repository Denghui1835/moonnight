# MoonNight · 项目规划书

> WaytoAGI 1024 超能 Coding 周末 · 游戏赛道
> 一个周末，把「我想做」变成「我做的」。

配套文档：[故事设定](故事设定.md)

---

## 1. 概念

**满月之夜，你在镜厅里跟着镜子中的"她"跳舞。跳错一个动作，身后的僵尸就会一拥而上——而你会成为他们中的一个。**

- 英文名：MoonNight ｜ 中文名：《月夜》
- 类型：体感节奏 / 恐怖 / 肉鸽（Roguelike）
- 单局：40 秒 – 2 分钟
- 平台：桌面浏览器，摄像头 + 键盘双模式

---

## 2. 核心画面

整个屏幕**就是一面镜子**。镜中同时有四层：

| 层 | 内容 | 作用 |
|---|---|---|
| 你的影子 | 摄像头实时骨架（或键盘模式下的替身） | 让玩家看见自己在跳 |
| 镜中人 | 只在镜中出现，房间里没有这个人，男女双版 | 老师，也是恐怖源 |
| 他们 | 背对镜子的一排僵尸，**一直在靠近** | 观众，也是处刑人 |
| 窗外 | 满月、老树、雾、乌鸦 | 唯一光源与气氛 |

**他们一步步逼近。** 跳对，他们退半步；跳错，他们猛扑一大步。贴到镜面上，就吃你。

**画面风格**：全片统一极简剪影（纯黑身体 + 圆形头），不写实、不加细节。恐怖靠"看不清"，不靠建模。

---

## 3. 玩法循环

```
推门（5 秒开场，可跳过）
  ↓
教学关（第 0 关）：她一个一个教，不判定、不死亡、可无限重看
  ├─ 随时「跳过教学」→ 直接进正式关
  └─ 随时「重看这个动作 / 重看全部」
  ↓
第 1 关：肉鸽开始，距离系统启用
  ↓
你按节拍跟做，逐个判定
  ↓
  对 → 他们退半步，雾气散去一点
  错 → 他们同时扑近一大步
  ↓
  被贴到镜面 → 惨叫 → 黑屏 1.2 秒 → 回到第 1 关
  ↓
跳完整关 → 乌鸦多一只，月亮偏一点，进入第 N+1 关
```

**死亡不是惩罚，是叙事**：每次重开，都是"下一个人推门进来"。

---

## 4. 节奏与难度

**要快、要动感**：没有静止的间隙，每个动作都咬着节拍。

| 关 | BPM | 每动作拍数 | 动作数 | 新变量 |
|---|---|---|---|---|
| 0 | 100 | 4 | 4 | **教学**：不判定、不死亡、可无限重看 |
| 1 | 128 | 4 | 3 | 肉鸽开始，他们入场 |
| 2 | 136 | 4 | 4 | 第一只乌鸦，动作组合变多 |
| 3 | 144 | 4 | 5 | 僵尸开始模仿你的错误动作 |
| 4 | 152 | 3 | 5 | 主动干扰：一只僵尸贴上镜面挡住视线 |
| 5 | 160 | 3 | 6 | 镜中人开始左右镜像反转 |
| 6+ | 168 | 3 | 6 | 程序生成组合，直到玩家失败 |
| 终章 | — | — | — | 镜中人跳一支你没见过的舞，揭晓「第一个」 |

**动感来自哪里**：
- 动作之间**不留空拍**，上一拍的落点就是下一拍的起点
- 镜头跟着节拍轻推；跳对时往前顶一下，跳错时猛推并抖
- 僵尸随节拍抽搐，越近频率越高
- 雾、光、乌鸦全部按拍子走，不按秒走

每关结束：2 拍静默，只有心跳和雾在动——然后下一关直接砸进来。

---

## 4.5 教学关（第 0 关）

**目标**：让第一次打开的人 20 秒内知道怎么玩，同时不破坏气氛。

| 项 | 设计 |
|---|---|
| 动作 | 4 个基础动作，一次只教一个 |
| 循环 | 她示范 2 遍 → 你跟 2 遍 → 给一句反馈 → 下一个 |
| 判定 | **不判定生死**，只显示"像"或"再来一次" |
| 重看 | 底部常驻按钮：重看这个动作 / 重看全部 |
| 跳过 | 右上角常驻「跳过教学」，直接进第 1 关 |
| 僵尸 | 不出现。镜子尽头只有很远的几个黑影，背对着 |
| 距离 | 不启用 |
| 时长 | 完整看约 60 秒，跳过只要 1 秒 |

**为什么可以无限重复**：叙事上她就是来教你的，镜子永远有耐心。重看不需要任何惩罚或限制。

从主菜单永远可以再进教学关，不会锁。

---

## 5. 判定（决定手感，最重要）

| 参数 | 值 | 说明 |
|---|---|---|
| 每动作 | 4 拍 | 前 2 拍示范，后 2 拍给玩家 |
| 判定窗口 | 最后 1.5 拍 | 取窗口内**最好的一帧** |
| 算法 | 8 组关节角度加权误差 | 与身高体型无关 |
| 通过阈值 | 0.55（宽松，待实测） | 一次错就死，所以必须给足容错 |
| 防误判 | 连续 8 帧低于阈值才算错 | 摄像头抖动不致命 |
| 键盘模式 | 方向键对应动作，按对即过 | 完全等价，不降难度 |

**自动降级**：摄像头不可用 / 光线太差 / 检测丢失超 2 秒 → 提示并切键盘，本局继续。

---

## 5.5 靠近循环（压力来源）

他们没有血条。他们在**循环**。

| 参数 | 值 | 说明 |
|---|---|---|
| 单次循环 | 8–12 拍 | 从最远处匀速挪到镜面前，近得能看见眼窝 |
| 循环终点 | 差一帧就抓到你 | 然后整排人**瞬间回到最远处**，重新开始 |
| 每关变化 | 循环更短、靠近更快 | 第 1 关 12 拍，第 5 关 8 拍 |
| 跳对 | 循环照常继续 | 你只是让这一晚继续下去 |
| 跳错 | **循环终止** | 不管他们离你多远，0.3 秒内扑到镜面 |

他们不是在走路，是在重复同一段路。

**视觉做法**：回退不做"后退"，而是整排人像掉帧一样**瞬移回远处**，同时画面轻微闪一下、雾重新合拢——他们被困在同一段胶片里。

你跳对了，这一晚就继续循环；你跳错了，这一晚就结束。

## 6. 叙事

- **出场**：5 秒推门镜头，镜中先浮出"我"，再浮出"它"
- **规则**：跳错的人被吃掉脑子，怨魂站进身后的队里——**他们不是同伴，是死在这里的人**
- **揭示**：第 1、3、5 关各一条字幕，只给现象，不解释
- **悬念**：「第一个被吃掉的人是谁」——只有玩到最后的玩家知道
- **终章**：最后一关，镜中人跳一支你没学过的舞，跳到最后一拍前回头看你——那里揭晓答案
- 完整设定见 [故事设定](故事设定.md)

## 7. 美术

- **画风**：全片统一**极简剪影**——纯黑身体、圆形头、细长四肢。没有五官、没有衣服细节。便宜、好动、越简单越瘆人。
- **男女双版**：男版＝直腿火柴人；女版＝肩上收窄、腰间张开一个**三角裙摆**（像厕所标识）。同一套骨架，只多画一个三角。
- **色调**：冷月青灰 `#b9d4cf` + 纯黑，血红 `#c2352d` 只在死亡瞬间出现
- **老树**：窗外的剪影，枝条像手指，静止不动——动的是雾
- **雾**：三层缓慢平移的半透明噪点，地面最浓
- **乌鸦**：偶尔落枝、突然起飞；每过一关多一只
- **他们的脸**：**只有头有细节**。远了是个黑圆，近了看见眼窝，更近眼睛反光，贴到镜面时能看清一直张着的嘴。脸随距离逐步"显影"。
- **镜中人**：比常人身形略长，轮廓边缘有一层极淡的月光。没有脸。
- **镜子**：边框、水银污渍、随关卡增长的裂纹

> 不做血腥。恐怖来自「它们在看」「你能看清它的脸了」「镜子碎了」。

## 8. 音频

Web Audio 实时合成，零版权素材，节拍时钟 = 音频时钟：

- 鼓：底鼓 + 军鼓 + 十六分踩镲，放克切分
- 贝斯：小调切分 riff
- 铺底：管风琴式和弦
- 音效：乌鸦、门轴、心跳、玻璃碎裂、**惨叫**
- 惨叫：锯齿波 + 三段共振峰 + 音高快速下滑，合成人声嘶吼；先是一群人同时发出的干哑声，再是你的
- 动态：每过一关加一层乐器并升半音；死亡时所有音轨瞬间抽空，只剩心跳和惨叫

## 10. 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 现场光线下识别不稳 | 致命 | 宽松阈值 + 连续帧防抖 + 一键切键盘 |
| 一次失误即死让评委挫败 | 高 | 前两关判定更宽；死亡到重开不超过 2 秒 |
| 推门镜头做不完 | 中 | 纯 2D 门板 + 推进 + 雾视差，不依赖 3D；做不完就切文字卡 |
| 网络差 | 中 | 模型 / wasm 全部本地 |
| 恐怖尺度 | 低 | 无血腥，规避直播风险 |
