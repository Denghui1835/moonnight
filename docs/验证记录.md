## 1. 本轮修复的两处风险

### 1.1 摄像头降级泄漏

`startGame("camera")` 中，`getUserMedia` 成功但 MediaPipe 模型加载失败时，原来的 `catch` 只切换了模式，没有关闭已打开的摄像头流。

修复（`src/main.ts`）：

```ts
} catch {
  tracker.stop();       // 显式停止轨道，避免摄像头指示灯常亮
  tracker = null;
  mode = "keys";
  video.classList.add("hidden");
  toast("摄像头打不开，已切到键盘模式");
}
```

验证（`qa.mjs` → camera leak run，网络层屏蔽 `*/wasm/*` 与 `*/models/*`）：

| 检查 | 结果 |
|---|---|
| 自动降级到键盘模式并提示 | PASS |
| 轨道真实关闭：`trackStates: ["ended"]`，`srcObject: null` | PASS |
| 两个开始按钮恢复可点 | PASS |
| 降级过程无页面报错 | PASS |

### 1.2 音频时钟单点故障

原来 beat 只从 `AudioContext.currentTime` 推。标签页被挂起、音频上下文暂停时，节拍会停或跳。

修复（`src/audio.ts` 的 `syncBeat()`）：

- `AudioContext.currentTime` 为主时钟；
- 检测到主时钟不前进时，用单调递增的墙钟增量兜底；
- 上下文恢复时重新锚定 `beatOrigin`，不补跳、不回退。

验证：

| 检查 | 数值 |
|---|---|
| 上下文挂起 1024ms，beat 仍前进 | `6.55 → 7.93 → 8.71`，期望增量 1.39，PASS |
| 恢复后 beat 不跳变 | 实测增量 `0.78`，期望 `0.64`，PASS |
| 音频初始化失败不会禁用开始按钮 | 代码路径 + 降级测试，PASS |

### 已修复：375px 教学栏挤压

在 375×812 下发现教学栏只有 188px 宽，三个按钮被挤成两行、按钮高 72px。

原因：`.tutorial-bar` 使用 `position:absolute; left:50%`，绝对定位的 shrink-to-fit 宽度被限制在包含块的一半（375/2 ≈ 188）。

修复（`src/style.css`）：

```css
.tutorial-bar {
  width: max-content;
  max-width: calc(100vw - 28px);
  justify-content: center;
}
.ghost.small {
  white-space: nowrap;
  flex: 0 0 auto;
}
```

复测：`scrollWidth 375 / innerWidth 375`，教学栏 `276×30`，三个按钮单行（100 / 76 / 76 px），HUD 与提示条均有非零尺寸。见 `docs/screenshots/06-phone.png`。

> 用 CDP 复测移动端时，页面必须 `Page.bringToFront()`，否则 headless 会暂停 rAF，截图为黑屏——这是测试环境问题，不是页面问题。

### 已修复：舞蹈板点不动

第一轮真机事件测试中，按钮高亮与判定全部失败，但合成 `PointerEvent` 能让游戏继续——说明监听器没问题，是命中测试失败。

原因：`#hud` 是 `pointer-events: none`（HUD 不挡画布），该属性会被子元素继承；`.touchpad` 没有显式恢复 `pointer-events`，于是触点直接穿过按钮落到画布上。

修复（`src/style.css`）：

```css
.touchpad {
  pointer-events: auto;
}
```

复测：真实 `touchStart` 即触发 `pointerdown`，按钮高亮、判定、计分全部通过。截图：`20-phone-title` / `21-phone-tutorial` / `22-phone-level`。

## 6. 已知限制

- **假摄像头没有人**：摄像头流程只验证了「模型加载、轨道、无人体时的宽松判定」，真实骨骼识别需要真人复测。
- **CDP 按键不是受信任输入**：部分判定用页面内 `pushKey` 驱动；另有一条真实 `Input.dispatchKeyEvent` 用例覆盖真实键路径。
- **触控是模拟手机**：17 项通过 CDP 设备模拟 + 真实 `dispatchTouchEvent`，未在实体手机上跑；`pointerdown/up` 路径与真机一致，但 Safari / iOS 仍需一次人工复测。
- **竖屏构图**：375px 下没有横向溢出、按钮全部可点，但场景仍按横屏构图缩放，领舞在竖屏里偏大，后续可单独做竖屏镜头。
- **WAV 体积**：11.6 MB，仓库可接受；演示优先用 1.6 MB 的 `moonnight-metal.mp3`。
- **摄像头测试偶发挂起**：headless 下摄像头 target 偶发整页冻结，导致一次轨道检查超时；重跑通过（32/32），未改动游戏代码。
