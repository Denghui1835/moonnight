## 1. 本轮修复的两处风险

### 1.1 摄像头降级泄漏

`startGame("camera")` 中，`getUserMedia` 成功但 MediaPipe 模型加载失败时，原来的 `catch` 只切换了模式，没有关闭已打开的摄像头流。

修复（`src/main.ts`）：

```ts
} catch {
  tracker.stop();       // 显式停止轨道，避免摄像头指示灯常亮
  tracker = null;
  mode = "keys";
  video.classList.add("hidden");
  toast("摄像头打不开，已切到键盘模式");
}
```

验证（`qa.mjs` → camera leak run，网络层屏蔽 `*/wasm/*` 与 `*/models/*`）：

| 检查 | 结果 |
|---|---|
| 自动降级到键盘模式并提示 | PASS |
| 轨道真实关闭：`trackStates: ["ended"]`，`srcObject: null` | PASS |
| 两个开始按钮恢复可点 | PASS |
| 降级过程无页面报错 | PASS |

### 1.2 音频时钟单点故障

原来 beat 只从 `AudioContext.currentTime` 推。标签页被挂起、音频上下文暂停时，节拍会停或跳。

修复（`src/audio.ts` 的 `syncBeat()`）：

- `AudioContext.currentTime` 为主时钟；
- 检测到主时钟不前进时，用单调递增的墙钟增量兜底；
- 上下文恢复时重新锚定 `beatOrigin`，不补跳、不回退。

验证：

| 检查 | 数值 |
|---|---|
| 上下文挂起 1024ms，beat 仍前进 | `6.55 → 7.93 → 8.71`，期望增量 1.39，PASS |
| 恢复后 beat 不跳变 | 实测增量 `0.78`，期望 `0.64`，PASS |
| 音频初始化失败不会禁用开始按钮 | 代码路径 + 降级测试，PASS |

### 已修复：舞蹈板点不动

第一轮真机事件测试中，按钮高亮与判定全部失败，但合成 `PointerEvent` 能让游戏继续——说明监听器没问题，是命中测试失败。

原因：`#hud` 是 `pointer-events: none`（HUD 不挡画布），该属性会被子元素继承；`.touchpad` 没有显式恢复 `pointer-events`，于是触点直接穿过按钮落到画布上。

修复（`src/style.css`）：

```css
.touchpad {
  pointer-events: auto;
}
```

复测：真实 `touchStart` 即触发 `pointerdown`，按钮高亮、判定、计分全部通过。截图：`20-phone-title` / `21-phone-tutorial` / `22-phone-level`。

### 同时补齐的两处触控细节

## 6. 已知限制

- **假摄像头没有人**：摄像头流程只验证了「模型加载、轨道、无人体时的宽松判定」，真实骨骼识别需要真人复测。
- **CDP 按键不是受信任输入**：部分判定用页面内 `pushKey` 驱动；另有一条真实 `Input.dispatchKeyEvent` 用例覆盖真实键路径。
- **触控是模拟手机**：21 项通过 CDP 设备模拟 + 真实 `dispatchTouchEvent`，未在实体手机上跑；`pointerdown/up` 路径与真机一致，但 Safari / iOS 仍需一次人工复测。
- **3D 帧率只在桌面测过**：桌面 Edge 60fps 稳定；手机竖屏按 1.5 倍像素比渲染并缩小人物，未在低端安卓机上实测帧率。
- **WAV 体积**：11.6 MB，仓库可接受；演示优先用 1.6 MB 的 `moonnight-metal.mp3`。
- **摄像头测试偶发挂起**：headless 下摄像头 target 偶发整页冻结，导致一次轨道检查超时；重跑通过（37/37），未改动游戏代码。

### 一个踩过的坑：镜像有两个域名，分属两套发布凭证

`moonnight-c1n29gwia6s.qoder.zone` 与 `moonnight-mirror-rvzkngbzcr9.qoder.website` 都能打开，但它们是两个独立站点：本会话的 Qoder Sites 凭证 `list_sites` 只返回 **zone** 这个项目（`月夜 MoonNight（国内镜像）`，`site_id 01a16c76-5484-7253-8d6b-bcce69af0a65`，access public），对它执行 `prepare_site` + `publish_site` 生效；**website** 那份要另一套凭证才管得了，从这里 `get_site` 报 `sites_request_failed`。

教训：只发一个域名，另一个就会停在旧包。本轮先把 zone 发到 `index-DKMki3oD.js`，随后 website 也补齐，**2026-10-24 15:50 三个入口实测一致**：

|---|---|
| GitHub Pages | `index-DKMki3oD.js` + `index-D_LXfvHZ.css` |
| 镜像 A（zone） | `index-DKMki3oD.js` + `index-D_LXfvHZ.css` |

## 9. 3D 渲染层验收（2026-10-24）

### 结构
