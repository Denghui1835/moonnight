# MoonNight · 月夜

> 满月的夜里，你走进一间废弃的排练厅，替一个没能跳完的人，把这支舞跳完。

参与 **WaytoAGI 1024 超能 Coding 周末 · 游戏赛道**

---

## 这是什么

一个恐怖节奏游戏。

你站在镜子前，镜子里有一个"人"在教你跳舞。你身后的队尾站着一排东西——
它们曾经也是来跳舞的人，跳错了，被吃掉了脑子，只剩怨魂留在这里。

它们一直在靠近。走到快要抓住你的时候，它们会像掉帧一样瞬移回最远处，然后重来。

**你跳对了，这一晚就继续循环；你跳错了，这一晚就结束。**

---

## 玩法

- **摄像头模式**：跟着镜中人的动作跳，摄像头实时识别你的身体
- **键盘模式**：方向键对应动作，完全等价，不降难度
- **教学关**：第 0 关不会死，可以无限重看，也可以直接跳过
- **肉鸽**：一旦跳错，不管它们离你多远，都会扑上来——回到第 1 关
- **六关之后**：还有一支你没见过的舞

## 本地运行

```bash
npm install

npm run build    # 产出 dist/
```

## 技术

| 模块 | 选型 |
|---|---|
| 构建 | Vite + TypeScript |
| 渲染 | Canvas 2D（程序化剪影，无图片素材） |
| 体感 | MediaPipe PoseLandmarker (lite)，模型与 wasm 已本地化 |
| 音频 | Web Audio 实时合成 |
| 输入 | 摄像头 + 键盘双模式 |

姿势模型与 wasm 运行时来自 [MediaPipe](https://github.com/google-ai-edge/mediapipe)（Apache-2.0），已随仓库本地化，运行时不依赖外网。

## 素材与原创性

- 代码、美术、音乐**全部原创**
- 美术为程序化生成的极简剪影，没有使用任何图片素材
- 音乐由 Web Audio 实时合成，没有使用任何第三方曲目
- 编舞为原创动作，未使用任何已有作品的编舞
